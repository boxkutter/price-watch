This page is a client app: a regular user (not an admin) calling the public API with a user token and a client token, the way a phone app or script would. Everything you do here is an ordinary API call; see the "API calls" tab.

API calls this page made

Every call sends Authorization: Bearer <user token> and X-Client-Token: <client token>. The effective permissions are what the user granted this client. Full guide: /api-guide.

curl -H "Authorization: Bearer $USER_TOKEN" -H "X-Client-Token: $CLIENT_TOKEN" \
     http://localhost:8085/v1/monitors
