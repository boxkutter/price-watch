Connectors

Install a connector

Upload a connector package (a zip built with python -m app.connectors.build). You review it before anything is installed, and a new connector starts disabled. Connector code runs inside this service with its privileges, so install only packages you trust.

Stores

Compare prices by barcode

In a shop, scan or type the barcode. Tick the stores you compare across in the Stores list. Prices the catalogue already knows appear at once; live prices follow.

Add a product by link

Paste a product page address from a supported store (City Gross, Coop, Willys or Lidl). The page is not fetched; only the product id is read from the link, then the store is asked for that one product.
